How LucioTiers works

1. Log in with Google
2. Create a tier list (players, items, strats)
3. Share a link with your SMP or community

Under the hood, this will run on Firebase Auth + Firestore, fully static on GitHub Pages with a free custom domain. No backend server to babysit.
